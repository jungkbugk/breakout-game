# 돌파 매매 시뮬레이터

종목명·시기를 가린 일봉 차트로 돌파 매매 감각을 훈련하는 모바일 친화 웹 게임입니다. 설치 없이 `index.html` 하나로 동작합니다.

## 모드
1. **성공 / 실패** — 피벗 돌파 매수 시 20일 후 +3% 초과일지 맞히기 (실전 비율 또는 반반 출제)
2. **베스트 고르기** — 서로 다른 4개 돌파 중 수익률 1등 고르기
3. **매매 연습** — 피벗 돌파 매수/패스를 고르고 하루씩 열면서 직접 매도, 손익을 R(1R=손절폭 8%)로 채점
4. **연속 매매** — 자본 100으로 시작해 돌파마다 비중(10~100%)을 정하고, 청산 방식(20일 보유 / 10일선 / 50일 EMA 이탈)은 자동. 끝나면 자본 곡선·최대 낙폭을 전부 25% 비중 매수와 비교

**📅 오늘의 문제**: 날짜를 시드로 모두에게 같은 5문제(국장 2·미장 3)를 ③ 방식으로 풀고, 결과를 이모지(🟩수익 🟥손실 ⬜패스 🟨놓친 성공)로 복사해 공유합니다. 서버 없이 동작하며 연속 참여일을 셉니다.
**④의 행동 점검**: 연패·큰 수익 뒤에는 흔들리기 쉬운 순간을 알려 주고, 그때 비중을 키우면 복수·과신 매매로 표시해 마지막에 횟수와 손익 영향을 보여줍니다.
**오답 노트**: ①·③·④에서 틀리거나 손실 본 사례(놓친 성공 포함)가 자동으로 쌓이고, 같은 사례를 2번 연속 잘 처리하면 빠집니다.
**거래 비용 옵션**: 켜면 왕복 국장 0.4%·미장 0.3%(수수료·세금·슬리피지)를 빼고 성공 여부와 점수를 계산합니다.

정답 공개 때 거래량 배수, 52주 고점 대비, RS 순위, 업종 내 위치, 지수 상태를 보여주고, 각 지표 구간의 **전체 돌파 사례 성공률**을 옆에 붙입니다. ③에서는 20일 보유·5/10/20일선·50일 EMA 이탈·추가매수 결과를 비교합니다. 기록은 각자 브라우저(localStorage)에만 저장됩니다.

## 매수 규칙
- 차트는 돌파 **전날**까지만 보입니다. 피벗(직전 60일 고점)을 돌파하는 순간 체결되고, 갭 상승이면 시가에 체결됩니다(갭 5% 초과 사례 제외).
- 손절 -8%(장중 저가 기준, 갭하락이면 시가 청산), 진입일 포함 20거래일 보유 후 종가 청산.
- 사례는 돌파 전날까지의 정보로만 고르며, 돌파일 종가·거래량은 선택에 쓰지 않습니다.
- 일봉만으로는 진입일 장중 순서를 알 수 없어, 시가가 피벗보다 낮은 상승일은 저가가 체결 전에 나온 것으로 봅니다.

## 검증 결과 (전체 돌파 약 8.8만 건, 비용 제외, 손절 -8% 포함)
- 지표: 국장은 52주 고점 -20% 이하(성공 21%)·거래량 부족·약한 지수 상태가 불리, 미장은 돌파일 거래량 3배 이상(성공 44%)·업종 상위 10%가 유리했습니다. 거래량은 돌파일 값이라 매수 시점에는 알 수 없는 사후 정보입니다.
- 청산(진입 후 최대 40일 안): 국장은 어떤 규칙도 평균 -0.2~0%로 이익이 없었고, 미장은 40일 보유 +0.97%·50일 EMA 이탈 +0.75%가 좋았으며 짧은 이평선 이탈과 추가매수는 더 나빴습니다.

## 알아둘 점
- 국장(KRX)·미장 일봉 약 8.8만 건의 돌파 사례에서 800문제를 추출했고, 실전 기저 성공률은 국장 약 24%, 미장 약 33%입니다.
- **생존 편향**: 현재 상장 종목만 사용해 상장폐지 종목이 빠져 있습니다. 수수료·세금·슬리피지는 "거래 비용" 옵션을 켠 경우에만 반영됩니다.
- 교육·연습용이며 투자 권유나 수익 보장이 아닙니다.

## 직접 만들기
`src/build_questions.py`는 로컬 백테스트 데이터(`backtest_v2/data`)가 있어야 실행됩니다. 데이터는 저장소에 포함하지 않았습니다.
`python build_questions.py` → `python build_html.py` 순서로 `index.html`이 생성됩니다.
