# 돌파 매매 시뮬레이터

종목명·시기를 가린 일봉 차트로 돌파 매매 감각을 훈련하는 모바일 친화 웹 게임입니다. 설치 없이 `index.html` 하나로 동작합니다.

## 모드
1. **성공 / 실패** — 피벗 돌파 매수 시 20일 후 +3% 초과일지 맞히기 (실전 비율 또는 반반 출제)
2. **베스트 고르기** — 서로 다른 4개 돌파 중 수익률 1등 고르기
3. **매매 연습** — 피벗 돌파 매수/패스를 고르고 하루씩 열면서 직접 매도, 손익을 R(1R=손절폭 8%)로 채점

정답 공개 때 거래량 배수, 52주 고점 대비, RS 순위, 업종 내 위치, 지수 상태를 보여주고, 20일 보유·50일선 이탈 매도 결과와 비교합니다. 기록은 각자 브라우저(localStorage)에만 저장됩니다.

## 매수 규칙
- 차트는 돌파 **전날**까지만 보입니다. 피벗(직전 60일 고점)을 돌파하는 순간 체결되고, 갭 상승이면 시가에 체결됩니다(갭 5% 초과 사례 제외).
- 손절 -8%(장중 저가 기준, 갭하락이면 시가 청산), 진입일 포함 20거래일 보유 후 종가 청산.
- 사례는 돌파 전날까지의 정보로만 고르며, 돌파일 종가·거래량은 선택에 쓰지 않습니다.
- 일봉만으로는 진입일 장중 순서를 알 수 없어, 시가가 피벗보다 낮은 상승일은 저가가 체결 전에 나온 것으로 봅니다.

## 알아둘 점
- 국장(KRX)·미장 일봉 약 4만 건의 돌파 사례에서 추출했고, 실전 기저 성공률은 국장 약 25%, 미장 약 34%입니다.
- **생존 편향**: 현재 상장 종목만 사용해 상장폐지 종목이 빠져 있습니다. 수수료·세금·슬리피지도 없습니다.
- 교육·연습용이며 투자 권유나 수익 보장이 아닙니다.

## 직접 만들기
`src/build_questions.py`는 로컬 백테스트 데이터(`backtest_v2/data`)가 있어야 실행됩니다. 데이터는 저장소에 포함하지 않았습니다.
`python build_questions.py` → `python build_html.py` 순서로 `index.html`이 생성됩니다.
